# 第九阶段：运行与工程化说明

## 本地隔离运行（Python 3.12）

```bash
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-lock.txt
python -m pip check
cp .env.example .env
chmod 600 .env
python -m scripts.preflight
python -m scripts.local_platform --data-dir data-local
```

打开 http://127.0.0.1:8000 ，Ctrl+C 停止。该模式是本机 HTTP 和 Python 检测，不运行 Kafka/Flink；保留独立的数据目录。环境变量优先于 `.env`。本阶段本地文件额外读取 `DB_TIMEOUT_SECONDS`、`EVIDENCE_OPERATION_TIMEOUT_SECONDS`、`EVIDENCE_RETENTION_DAYS`、`FAST_STATE_MAX_KEYS`、`LOG_LEVEL`。预检不连接数据库、模型或 Docker，不能证明服务可用；输出只包含检查名与状态，不输出配置值。`ok=true` 允许 warning：无模型时规则回退，未配置模拟器 token 时控制未受保护，API 没有用户认证。`--env-file` 使用 local launcher 相同的解析方式，不代表 Compose 对 `.env` 的解析完全相同。

锁文件记录本次 Python 3.12 解析出的全部运行依赖版本，但未锁定包哈希、系统库、Python 补丁版本或容器镜像摘要，不是完全可重复或供应链安全保证。CI 配置是 `.github/workflows/tests.yml`，本轮未在 GitHub 执行。Docker 的部署命令仍参阅项目 README 原有说明；本轮没有 Docker，不能确认能从干净环境构建。

## 配置与密钥边界

只在可信本机隔离环境运行。默认平台 API 包括故障注入功能，没有用户身份认证、授权或完整 CSRF 防护，模拟器 token 只保护模拟器端点，并不能保护平台 API。loopback 绑定不等于浏览器或同机其他进程的安全边界。未经架构改造和安全评估不要对公网或不可信容器网络暴露。模型密钥仅通过环境变量或本地私有 `.env` 提供，勿打印或提交。预检不扫描全部源代码、历史记录和日志；密钥命名过滤是防护层而非密钥泄漏证明。环境中其他不符合过滤规则的凭证仍可能传给子进程，敏感场景请使用最小化环境启动。`.gitignore` 无法保护已经被追踪或已经提交的文件。

## 数据库与恢复

本阶段没有引入数据库迁移或自动清理，也没有对包内历史数据库执行写入。现有 Store 第七、第八阶段迁移逻辑和备份规则不变，详见 `docs/phase7/可靠性部署与恢复指南.md` 与 `docs/phase8/证据管理部署与架构.md`。升级前应停止写入者，使用 SQLite 在线 backup API 创建一致备份；遇到无法读取的库，保留 DB/WAL/SHM 现场后人工处理。现有基础表的初始化先于 phase7/8 备份，不是完善的通用迁移框架。不要在运行时覆盖数据库或移除 WAL/SHM。
