动态学习使用结束时间有序的已关闭窗口，按窗口长度间隔采样基线，避免把重叠窗口当独立样本。保留固定检测 API、规则ID、独立快速5xx及恢复逻辑。动态告警新增可追溯的模式、配置哈希、基线数量、median/MAD及实际阈值。不同模式的告警使用不同稳定ID。

优先运行现有回归和纯 Python/实际本地集成；只有 Kafka/Flink 进程实际启动且验证通过才记录真实流成功。工具或下载受阻时记录原始原因，不用 mock 替代部署结果。无需任何 LLM API 调用。

## 集成检查后新增的必要兼容修改

动态阈值可能低于原800ms/90%固定值，因此单独接入检测器会导致恢复逻辑提前判定健康、RCA无法识别实际动态异常。新增app/detection_policy.py，微调app/incidents.py和app/rca.py，仅向对应服务传播告警阈值，保留其他服务和旧报告语义。已增加持续300ms异常不得恢复、恢复后可关闭、跨服务阈值不串用和真实证据引用测试。
